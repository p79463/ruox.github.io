# ruox.github.io

> 我的个人博客：https://www.ruox.cc.cd/

### 介绍

这是基于 [asorn-open](https://github.com/asorn/button-open) 主题定制的个人博客，经过全面内容改造，呈现我的个人项目、技术笔记和工作经历。

### 内容结构

| 页面 | 说明 |
|------|------|
| Home (`index.html`) | 首页，可交互的 typed.js 效果 + 项目快速链接 |
| Work (`work.html`) | 项目作品集：AI/LLM、嵌入式、逆向工程等方向 |
| Blog (`blog.html`) | 技术博客与知识库文章索引 |
| About (`about.html`) | 个人简介、工作经历、联系方式 |

### 技术栈

- 纯静态 HTML + CSS + JS
- 暗色主题 + 微动效（烟花、星空、魔法光效）
- 适配移动端
- 通过 GitHub Pages 部署

### 本地预览

```bash
# 直接在浏览器打开 index.html 即可
# 或使用 Python 启动本地服务器
python3 -m http.server 8000
```

### 部署

GitHub Pages 自动部署，CNAME 绑定 `www.ruox.cc.cd`。
