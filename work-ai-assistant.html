    AI 私人助理系统

    AI LLM RAG Agent MCP
    Python LangChain FastAPI FAISS 硅基流动API Streamlit CodeBox MCP

    项目简介

    基于 LangChain 和 FastAPI，搭建具备知识库检索、工具调用、代码解释器、多轮对话能力的私人 AI 助理系统。 通过硅基流动 API 接入大模型，结合 RAG 知识库与混合检索技术，实现高效、精准的智能问答与任务执行。

    技术栈

    Python LangChain FastAPI FAISS 硅基流动API Streamlit CodeBox MCP

    项目职责

    • 通过硅基流动 API 接入 Qwen2.5-72B-Instruct 大模型，完成推理参数调优
    • 基于 LangChain 构建 ReAct 范式 Agent，集成天气查询、网络搜索、知识库检索、代码解释器
    • 实现 RAG 知识库模块，支持多格式文档加载（PDF/TXT/CSV/MD/DOCX）、文本分割策略、FAISS向量存储与检索
    • 实现 FAISS + BM25 混合检索，中文场景召回准确率提升约 15%
    • 使用 FastAPI 搭建 RESTful 后端服务，实现对话接口与知识库管理
    • 自定义异步回调处理器，实现 LLM 推理结果的流式输出
    • 集成 CodeBox 沙箱实现代码解释器功能，支持 Python 代码安全执行与图片渲染
    • 基于 MCP（Model Context Protocol）扩展 Agent 工具链

    项目成果

    • 成功搭建端到端的 AI 助理系统
    • 掌握大模型应用开发完整技术栈
    • 积累了 FAISS 向量数据库使用经验和混合检索调优实践
