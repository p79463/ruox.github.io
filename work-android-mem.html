    Android 内存分析与可视化工具

    Android Root 系统工具 内核 可视化
    C/C++ Lua ImGui OpenGL Vulkan Linux内核模块

    项目简介

    在 Android Root 环境下，独立开发了集内存分析、数据可视化于一体的系统级工具， 从脚本开发到 Native 二进制程序，逐步深入系统底层技术栈。

    技术栈

    C/C++ Lua ImGui OpenGL Vulkan Linux内核模块

    项目职责

    • 使用 Lua 编写内存分析脚本，基于 GG 修改器框架实现进程内存扫描、数据特征识别与批量处理
    • 设计内存读写逻辑，实现数据类型判断、条件过滤、循环遍历等复杂业务逻辑
    • 使用 C/C++ 重构为 Native 二进制程序，脱离第三方工具依赖
    • 集成 ImGui 即时模式 UI 框架，结合 OpenGL/Vulkan 图形 API 实现数据可视化界面
    • 对接 Linux 内核模块(KO)驱动，实现系统级内存读写
    • 设计 TouchManager 过检测触摸库，解决设备触摸事件注入的 uinput 冲突问题

    项目成果

    • 完成了从脚本语言到编译型语言、从依赖工具到独立程序的技术演进
    • 深入理解 Android 系统内存管理机制、进程权限模型和 Root 环境下的系统级操作
    • 掌握了 ImGui 与图形 API 的集成方案，具备跨平台 GUI 开发能力
    • 积累了 Linux 内核模块对接经验
