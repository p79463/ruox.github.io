    ⚡ 项目职责

    🧩 Agent 框架

    • 配置并调优 Hermes Agent 框架核心参数，包括 Tool Calling、Context Compression、Reasoning Effort 等工作参数
    • 实践多 Agent 协作模式：Hermes Agent 作为主调度器，Codex / Claude Code 作为编码执行子 Agent
    • 通过 Skill 机制 沉淀可复用的过程知识，实现 Agent 自学习能力
    • 配置 Cron 定时任务 调度，实现 Webhook 事件驱动的自动化工作流

    🔧 工具链

    • 搭建 MCP Server/Client，集成外部工具链到 Agent 生态，实现标准化工具接入协议
    • 部署跨平台网关（Telegram / 终端），实现多渠道 AI 助手访问入口
    • 使用 AI Coding Agent 辅助开发与调试，提效约 40%
    • 基于 FastAPI 构建 RESTful API 网关层，统一管理 Agent 服务
