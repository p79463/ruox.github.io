    OLLVM 代码混淆工具链

    LLVM 混淆 编译器 安全 NDK
    LLVM 19 Clang C++ CMake Android NDK r28c ARM64

    项目描述

    基于 OLLVM 开源项目，在 LLVM 19 版本上独立完成代码混淆 Pass 的移植、集成与工程化。 实现控制流扁平化（Flattening）、虚假控制流（BogusControlFlow）、 指令替换（Substitution）等 LLVM Pass，并集成到 Android NDK 交叉编译工具链中。

    技术栈

    LLVM 19 Clang C++ CMake Android NDK r28c ARM64 Cross-Compilation

    项目职责

    • 完成 OLLVM 混淆 Pass 从 LLVM 14 到 LLVM 19 的移植适配，涉及 API 变更适配、Pass Manager 重构与调试
    • 实现控制流扁平化 Pass（Flattening），将循环+分支结构压平为 switch-case+dispatcher
    • 实现指令替换 Pass（Substitution），将标准算术/逻辑运算替换为等价的复杂指令序列（如 a+b → (a^b)+2*(a&b)）
    • 实现虚假控制流 Pass（BogusControlFlow），在原始控制流中插入不可达基本块增加 CFG 复杂度
    • 设计四级混淆模式（OFF/BASIC/MEDIUM/FULL），通过 CMake per-file 属性精细控制不同源文件的混淆策略
    • 集成分层混淆策略：核心代码全量保护（控制流扁平化+虚假控制流+指令替换），驱动模块仅指令替换
    • 集成字符串编译期加密、反调试、ARM64 花指令、调用混淆等多层防护

    项目成果

    • 完成 LLVM 19 版本完整混淆工具链，稳定支撑 Android Native 程序的生产编译
    • 深入了解 LLVM 编译器体系架构、Pass 机制和代码优化/变换原理
    • 掌握 LLVM 新版本（17→19）API 演进与迁移经验，具备编译器工具链工程化能力
