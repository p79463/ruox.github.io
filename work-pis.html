    ⚡ 项目职责

    🔄 系统设计

    • 独立负责广播系统 软件架构设计，从 0 到 1 搭建控制盒固件框架
    • 设计 LCD 屏信息显示 与界面交互逻辑，实现站点信息实时刷新
    • 开发 外部 Flash 存储 模块，管理音频资源与配置文件
    • 实现 IAP 在线固件升级，支持列车运营中远程更新
    • 完成 功能按键 交互逻辑与音量调节、越站功能

    📡 通信协议

    • 开发 CAN 通信模块，接收信号系统广播指令与站点编号
    • 实现 RS232 / RS485 双串口通信，与列车主机冗余交互
    • 通过 FatFs 文件系统 读取音频文件，SPI 推送至 VS1063 编解码播报
    • 解析接收数据识别 播放音频编号及顺序，实现全自动报站
    • 优化通信协议与数据处理逻辑，确保 高负载下系统稳定
