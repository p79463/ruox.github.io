    地铁广播 PIS 系统

    为国内外多条地铁列车开发的广播乘客信息系统，实现全自动广播报站与站点信息显示

    C STM32F1/4/7 FreeRTOS CAN RS232 RS485 FatFs VS1063 IAP

    📋 项目概述

    为国内外多条地铁列车开发的广播 PIS（乘客信息系统）系统。根据信号系统数据， 实现全自动广播报站和站点信息显示。系统基于 STM32 平台，搭载 FreeRTOS 实时操作系统，通过 CAN / RS232 / RS485 多种通信接口与列车主机交互， 使用 FatFs 文件系统管理音频资源，经 VS1063 编解码模块完成语音播报， 并支持 IAP 在线固件升级。

    ⚡ 项目职责

    • 模块设计：负责 LCD 屏信息显示、CAN 通信、外部 Flash 存储、功能按键、界面逻辑交互、IAP 在线升级模块
    • 确保控制盒能发送命令设置广播站点信息、实现自动报站、越站功能、调节音量
    • 开发 CAN 通信、外部 Flash 存储、RS232、RS485 通信模块
    • 通过 RS232 / RS485 / CAN 接收主机数据，识别播放音频编号及顺序
    • 使用 FatFs 文件系统读取音频文件，通过 SPI 推送到 VS1063 编解码模块播报
    • 在控制盒 LCD 屏 上实时显示站点信息

    02
