    座位预订显示系统

    国外某地铁列车座位预订显示系统，通过提升地铁乘客信息系统的智能化水平，便于乘客实时了解座位占用信息，提高乘车体验。

    #嵌入式 #CAN总线 #LCD触控 #IAP升级 #量产项目
    C STM32 CAN FatFs LCD IAP
    CAN 总线
    多节点可靠通信
    触摸交互
    LCD 触控界面
    批量工装
    上位机批量管理
    国外地铁量产
    已投入实际运营

    🏗️ 系统架构

    数据流架构
    上位机工装 → CAN 总线 → 座位屏节点
    (STM32)     → LCD 触摸显示

    ⚡ 项目职责

    💻 软件开发

    • 基于 STM32 平台完成全套嵌入式软件设计
    • CAN 总线通信协议制定与中断驱动实现，确保数据实时性
    • LCD 触摸屏 驱动及座位状态显示界面开发
    • FatFs 文件系统集成，管理配置与素材数据
    • 实现 IAP 在线升级，支持固件及素材远程更新
    • 外部存储驱动开发，确保数据可靠读写

    🔧 工装设计

    • 设计 上位机工装软件，通过 CAN 总线与节点通信
    • 实现批量操作：固件更新、素材下发、配置修改、远程重启
    • 制定并固化 CAN 总线通信协议，兼容多节点数据交互
    • 工装端集成 FatFs，管理待升级的程序与字库文件
    • 开发 LCD 批量管理界面，提升产线部署效率
    • 编写工装操作文档，支撑生产与售后团队
