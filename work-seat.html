    座位预订显示系统

    国外某地铁列车座位预订显示系统，通过提升地铁乘客信息系统的智能化水平，便于乘客了解座位占用信息

    C语言 STM32 CAN总线 FatFs LCD触摸屏 IAP在线升级

    📋 项目概述

    国外某地铁列车座位预订显示系统，通过提升地铁乘客信息系统的智能化水平，便于乘客了解座位占用信息。 系统基于 STM32 平台，采用 CAN 总线 实现各节点间数据通信， 使用 LCD 触摸屏 提供直观的座位状态交互界面，并通过 FatFs 文件系统管理存储数据。 支持 IAP 在线升级，方便系统固件及素材的远程更新维护。

    🏗️ 系统架构

    通信架构
    上位机工装 → CAN 总线 → 座位节点
    (STM32)     → LCD 触摸屏 → 乘客交互

    ⚡ 项目职责

    • 负责系统软件设计：CAN 总线通信、外部存储、触摸模块、LCD 座位信息显示、下位机在线升级模块
    • 编写底层驱动程序，确保各模块顺畅通信与有效控制
    • 在系统间 CAN 通信 中引入中断机制，确保数据接收的即时性
    • 制定通信协议，通过 CAN 总线接收站点数据、升级命令、素材数据
    • 设计工装软件，使用 FatFs 存储待更新的程序、素材、字库
    • 通过 LCD 屏幕 实现批量操作：发送更新、配置、重启命令

    🏆 项目成果

    01
    项目从 0 到 1 落地，量产投入使用
    02
    独立负责软件开发，实现座位占用情况实时显示
    03
    独立负责上位机工装开发，显著降低升级更新复杂度
